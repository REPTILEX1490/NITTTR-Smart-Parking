About the Project

🎯 Objective

The project develops an AI-based parking occupancy prediction system for the NITTTR Bhopal campus. The system predicts future parking occupancy and availability using historical parking data.

🧠 Artificial Intelligence

The system compares multiple machine learning algorithms and selects the best-performing model for prediction.

🤖 Machine Learning Models

  • Linear Regression
  • Decision Tree
  • Random Forest
  • Gradient Boosting

🅿 Parking Areas

  • P1 - Car Parking - 25 spaces
  • P2 - Car Parking - 30 spaces
  • P3 - Bike Parking - 35 spaces

⚙ Technologies

  • Python
  • Pandas
  • NumPy
  • Scikit-learn
  • Flask
  • HTML
  • CSS
  • JavaScript
  • Chart.js

🚫 No Camera Required

The system does not use cameras, computer vision or IoT sensors. It is a software-based machine learning prediction system using historical parking observations.

⚠ Important Limitation

Prediction quality depends strongly on the amount and quality of historical data. More real observations across different days, weeks, holidays and events will improve the system.
